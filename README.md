# Linux-Networking-Cloud-Infrastructure
Linux, Networking & Cloud Infrastructure Internship Project

## Final Project Outcome

Successfully created an Ubuntu Linux server in Oracle VirtualBox, configured networking and firewall rules, installed and enabled Nginx, and deployed a test website.

The website was accessed successfully from the Windows host using VirtualBox NAT port forwarding.
