
# Networking Fundamentals

## Objective
To understand fundamental networking concepts and configure basic network settings in Linux.

## Topics Covered

1. IP Addressing
2. DNS Configuration
3. Network Ports
4. Firewall Configuration
5. Security Group Configurations
6. Network Connectivity Testing

## Practical Implementation

- Identify the system IP address.
- Check network connectivity.
- Understand DNS resolution.
- Identify open and listening ports.
- Configure firewall rules.
- Test network communication.

## Tools and Commands

- ip addr
- ping
- nslookup
- curl
- ss
- ufw
